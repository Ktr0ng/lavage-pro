# LAVAGE PRO

Application web de gestion d'un centre de lavage automobile.

## Fonctionnalités prévues
- Enregistrement des prestations et recettes en FCFA
- Tableau de bord et historique
- Satisfaction client, incidents et observations
- Export Excel et sauvegarde/restauration
- Fonctionnement hors connexion sur Android

## Technologies
React, TypeScript, Vite, Tailwind CSS et IndexedDB.
